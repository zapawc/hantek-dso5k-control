# Local project instructions

Keep hardware access opt-in and separately approved. Never probe or open USB from installation, imports or tests. Retain the cooperative lease, validated device access, settled history, receive-only gates and raw evidence for permitted operations. Do not run scope configuration, calibration, clock or firmware writes without separate authorization. Do not reset endpoints or retry writes automatically.

Keep historical research, raw traffic, firmware and instrument backups outside this project. Preserve concurrent work. GitHub publication requires explicit approval. Consumers pin immutable reviewed commits or verified artifacts and call the documented CLI. CI runs only offline tests.

Starting with the next development approval, complete a [Prior Art and Reuse Assessment](docs/prior-art/INDEX.md#prior-art-and-reuse-assessment) before proposing or starting capability work and include it in the development return. Search the public repository, issues, PRs, ADRs and qualification records, then inspect authorized local evidence and fixtures. Reuse verified implementations and evidence within their demonstrated scope. Update the index when evidence or support changes. Propose the smallest additional test only for a specific material evidence gap. Keep exact restricted evidence locations in the local record.

For shared Hantek work raised by CYD-RF-Diagnostic, Digital Workbench or another consumer, use the GitHub Issue workflow once provisioned. Until then, draft the issue locally. Record the originating project and issue, immutable pin, exact sanitized CLI invocation, expected and actual results, primary and strict session status, evidence, safety boundaries and acceptance criteria. Consumer test methods, thresholds, analysis and presentation stay with the consumer. An issue is a handoff and grants no hardware or publication approval.

See [the engineering workflow](CONTRIBUTING.md), [the portable consumer guide](HANTEK_INTEGRATION.md), and [HANTEK-ADR-001](docs/adr/0001-cross-project-integration.md).
