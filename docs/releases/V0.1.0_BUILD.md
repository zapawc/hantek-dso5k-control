# Reproduce the preview wheel

## Scope and inputs

Build the approved full commit from a clean Git archive. The release manifest records the exact commit and artifact digest. Tested platform is Windows 11 x64, CPython 3.11.7 x64, pip 23.2.1 from that interpreter's ensurepip, and PowerShell 5.1. Capture manifest and settings schema versions are 2.0. The CLI wheel uses a cross-platform Python tag, and the preview claim for instrument access is limited to Windows and the tested target. Other Python versions allowed by package metadata are outside this qualification.

Use the [build lock](v0.1.0-build.lock) in an isolated build environment. The [Windows backend lock](v0.1.0-win-amd64-backend.lock) is for the separate runtime install. Obtain each wheel from its upstream distribution and compare SHA-256 before using it. The Hantek release attaches its own wheel and metadata. It links to the vetted upstream backend wheels and their hashes.

## Offline build

Extract `git archive --format=zip <exact-approved-sha>` into an empty source directory, preserving Git's archived file bytes. Use an absolute path for the approved wheelhouse. Run the following from the extracted source with CPython 3.11.7 x64. The build environment and output directory should be new.

~~~powershell
python -m venv ..\preview-build
$BuildPython = (Resolve-Path ..\preview-build\Scripts\python.exe).Path
& $BuildPython -m pip --version
& $BuildPython -m pip --disable-pip-version-check install --no-index --find-links $ApprovedWheelhouse --require-hashes -r docs/releases/v0.1.0-build.lock
$env:SOURCE_DATE_EPOCH = '1767225600'
$env:PYTHONHASHSEED = '0'
& $BuildPython -m pip --disable-pip-version-check wheel --no-index --no-deps --no-build-isolation --no-cache-dir --wheel-dir ..\preview-dist .
Get-FileHash ..\preview-dist\hantek_dso5k_control-0.1.0-py3-none-any.whl -Algorithm SHA256
~~~

Check each command's exit code before continuing. Run twice in separate source and build directories and require equal wheel bytes. Install by hash in a fresh consumer environment with the verified backend lock, run `pip check`, and exercise the installed CLI offline. Compare transport and protocol files against the qualified local baseline. Replay the schema migration offline and verify the approved notices. No USB operation is part of building or testing.
